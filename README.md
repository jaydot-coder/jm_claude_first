# jm_claude_first

네이버 블로그 작업을 돕는 로컬 도구 모음입니다.

- **[`photo-organizer/`](photo-organizer/)** — Galaxy·iPhone 사진이 Google Drive와 네이버 클라우드에
  나뉘어 백업된 것을 실제 촬영시각순 라이브러리 하나로 정리합니다.
- **[`blog-assistant/`](blog-assistant/)** — 초안 마크다운과 사진 폴더를 미리보기 HTML 한 장과
  삽입 순서대로 번호 붙은 JPEG 폴더로 렌더링합니다.
- **[`mcp/`](mcp/)** — Claude Code로 세법을 조사할 때 쓰는 MCP 서버 설정(법제처 국가법령정보).
  서버는 루트 `.mcp.json`에 커밋되어 있어 다른 PC에서도 clone 후 인증키만 넣으면 바로 붙습니다.
